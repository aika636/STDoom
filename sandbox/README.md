# Стенд Фазы 0

Голый HTML + `emulators` + DOOM, без SillyTavern. Цель — снять блокеры до того, как
написан UI (план §8, Фаза 0): проверить CSP, померить производительность и подтвердить
три «неподтверждённых» факта разведки.

```
node sandbox/serve.mjs      # http://127.0.0.1:8123/sandbox/phase0.html
```

Сервер отдаёт файлы из корня репозитория и **не ставит никаких CSP-заголовков** — это
контрольная точка: если здесь работает, а в таверне нет, виновата именно её CSP.

Что смотреть на странице:

1. **CSP** — блок «Проверки» вверху: `eval` и Worker из `blob:`-URL. Оба должны быть OK.
   Если нет — это блокер проекта (план §10).
2. **Производительность** — счётчик fps и `asyncifyStats()`. Признак перекрута циклов —
   не падение fps, а заикания и выпадения звука (план §4.9).
3. **rgba всегда null** — счётчик кадров с ненулевым `rgba` обязан остаться нулём.
4. **cycles на лету** — кнопки меняют циклы через `sendBackendEvent`; скорость должна
   меняться без перезапуска.
5. **Офлайн-сборка** — если страница запустилась, `doom.zip`, собранный
   `tools/build-bundle.mjs`, рабочий.

Результаты замеров записываются в `docs/development.md`.
