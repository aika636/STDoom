# Отладочный стенд

Голый HTML + `emulators` + DOOM, без SillyTavern. Нужен, чтобы отделять поломки самого
эмулятора от поломок интеграции с таверной: если здесь работает, а в таверне нет —
дело в таверне.

```
node sandbox/serve.mjs      # http://127.0.0.1:8123/sandbox/phase0.html
```

Сервер отдаёт файлы из корня репозитория и **не ставит никаких CSP-заголовков** — это и
есть контрольная точка для сравнения.

Что смотреть на странице:

1. **CSP** — блок «Проверки» вверху: `eval` и Worker из `blob:`-URL. Оба должны быть OK;
   без них эмулятор не запускается в принципе.
2. **Производительность** — счётчик fps и `asyncifyStats()`. Признак перекрута циклов —
   не падение fps, а заикания и выпадения звука: SB-DMA не успевает. Это контринтуитивно,
   и об этом стоит помнить при отладке.
3. **rgba всегда null** — счётчик кадров с ненулевым `rgba` обязан остаться нулём. Кадр
   приходит как RGB, три байта на пиксель; ветки под RGBA в рендерере нет намеренно.
4. **cycles на лету** — кнопки меняют циклы через `sendBackendEvent`; скорость должна
   меняться без перезапуска игры.
5. **Офлайн-сборка** — если страница запустилась, `doom.zip`, собранный
   `tools/build-bundle.mjs`, рабочий.
