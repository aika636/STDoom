# STDoom

UI-расширение [SillyTavern](https://github.com/SillyTavern/SillyTavern), которое запускает
**оригинальный DOS-DOOM 1993 года** в окне поверх чата.

Внутри — настоящий DOSBox, скомпилированный в WebAssembly
([js-dos / `emulators`](https://js-dos.com/)), и shareware-эпизод DOOM. Никакой сети,
никакого сервера, никакого участия языковой модели: расширение работает полностью
офлайн и в чат не заглядывает.

## Возможности

- DOOM в модальном окне таверны: клавиатура, мышь, звук и музыка (OPL-синтез через
  эмулированный Sound Blaster — тот самый, из 1993-го).
- Сохранение прогресса между сессиями: сейвы штатные, F2/F3 внутри игры, и переживают
  не только закрытие окна, но и выход из DOOM его собственным меню.
- Громкость и скорость эмуляции меняются на лету и запоминаются.
- Справка по управлению прямо в окне: раскладка тут не оригинальная — ходят на WASD,
  а стрелки только поворачивают.
- Тач-управление для планшета и геймпад. Оба написаны и покрыты тестами, но живьём
  не проверялись — ни настоящего пальца по планшету, ни настоящего геймпада через них
  ещё не прошло. На телефоне запускается и играется, но тесно: он с самого начала был
  заявлен как «хотя бы потыкаться».
- Свой IWAD: файл выбирается в настройках окна и остаётся в браузере.

## Установка

Расширения ставятся встроенным менеджером SillyTavern: **Extensions → Install extension**
и URL этого репозитория. Ручной способ — положить каталог в
`SillyTavern/data/<user>/extensions/STDoom` и перезагрузить страницу.

После установки в меню «волшебной палочки» появится пункт **STDoom**; та же команда
доступна как `/doom`.

## Управление

Раскладка **не оригинальная**, и это главное, что стоит знать заранее: в DOOM 1993 года
стрелки ходили, здесь они только поворачивают. Первый живой игрок об этом не знал и
застрял в первой комнате E1M1, решив, что дверь заперта. Та же табличка есть в панели
настроек прямо в окне.

| Клавиши | Что делают |
|---|---|
| `W` `A` `S` `D` | ходить: вперёд, назад и шагом вбок |
| `←` `→` | поворот камеры (вперёд **не** идут — для этого `W`) |
| `Пробел` | открыть дверь, нажать переключатель |
| `Ctrl` | огонь |
| `Shift` | бег |
| `1`…`7` | выбор оружия |
| Мышь | поворот; ЛКМ — огонь, ПКМ — шагом вбок, средняя — вперёд |
| `Esc` | меню DOOM — окно таверны этим **не** закрывается |
| `Tab` | карта уровня |
| `F2` / `F3` | сохранить и загрузить игру |

Вертикальная ось мыши не проброшена намеренно: в ванильном DOOM она двигает вперёд-назад,
а не смотрит вверх. На планшете и телефоне вместо этого рисуются экранные кнопки,
геймпад подхватывается сам — Chrome отдаёт его только после первого нажатия любой кнопки.

## Сборка игрового бандла

Бинарники DOOM лежат в репозитории как есть, но эмулятору нужен собранный архив:

```
node tools/build-bundle.mjs
```

Скрипт проверяет MD5 исходных файлов и собирает `assets/doom/doom.zip`. Пересборка
детерминирована: одинаковый вход даёт побайтово одинаковый архив.

## Разработка

Сборки нет: plain ES-модули и CSS, браузер грузит их напрямую. Подробности, команды и
чеклист ручной проверки — в [`docs/development.md`](docs/development.md); решения и их
обоснования — в [`docs/plan.md`](docs/plan.md).

```
node tests/run.mjs        # юнит-тесты
node sandbox/serve.mjs    # стенд без таверны, для замеров и отладки эмулятора
```
